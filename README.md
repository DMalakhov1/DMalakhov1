# Dmitry Malakhov

ML/NLP Developer focused on RAG systems, LLM fine-tuning, and applied machine learning.

I build end-to-end ML projects: a hybrid FAQ + RAG + SQL Telegram assistant for university
applicants, a Russian LLM fine-tuning pipeline trained on 8,641 labeled examples, and
reproducible ML workflows for NLP, computer vision, ranking, and tabular modeling.
